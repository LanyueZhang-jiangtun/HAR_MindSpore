## 五、必须交接的约定与结论（分散在各处，接手人最容易踩空）

1. **部署定调**：4 类 `walk/stairs/bike/jog`，静态交给 GPS 测距（IMU 不解静态）；**bike = 防作弊第一优先级**（校园跑场景核心）。
2. **数据规范**：固定 30 秒/段（=10 个 3s 窗）；命名 `P{编号}_{活动}_{位置}_{日期}.csv`；位置写文件名 + CSV `position` 列；label 列拼写 `bike/walk/stairs/run(=jog)/static(类外)`。
3. **已证实的结论（别重复做这些实验）**：
   - 跨设备：**特征通路（26 维 RF/模值特征）全面优于原始波形 CNN**，三次独立证实（P01、P04、P02）；
   - "手机数据 + 重训"是跨设备唯一有效路径，但收益**个性化**：同被试 93%、跨被试上限 ~60%（P02 验证）；
   - **微调数据必须覆盖全 4 类**（P04 无 stairs → 微调后 P02 的 stairs 段实测变差）；
   - **位置是主导因素**：口袋/背包可用；"手持看屏 + 低幅活动（walk/run）"是物理盲区（手机静止，IMU 看不到腿），只有 GPS 速度能补；
   - bike 最可迁移（蹬踏周期显著），stairs 最弱（与 walk 步频接近）。
4. **工程坑**（报告 §5 有完整记录，此处点名）：
   - numpy <2；`ms.export` 格式串必须大写 `"MINDIR"`；
   - 子 Cell 里 `load_checkpoint` 会**静默不加载**（权重没生效但无报错）；
   - 测试集标准化必须用**训练折**的 mean/std，不能用全量；
   - 全批量 80ep / lr=1e-3 安全；300ep / lr=0.02 会 NaN 发散。
5. **git 约定**：提交作者 `LanyueZhang-jiangtun <2102639794@qq.com>`（仓库级 config，新机器 clone 后保留）；交接机到 GitHub 网络**间歇性不可达**，push 失败重试即可，不要换凭据。
